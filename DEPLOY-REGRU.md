# Как опубликовать бег#заЧанку на REG.RU — пошагово

Как это устроено: файлы сайта лежат на GitHub. GitHub сам собирает из них сайт и по FTP выкладывает его на хостинг REG.RU.
Раз в 30 минут он же проверяет ваш Telegram-канал и обновляет анонс на сайте.

Уже сделано:
- ✅ домен zachanku.ru зарегистрирован;
- ✅ хостинг подключён, сайт zachanku.ru создан, папка `/www/zachanku.ru`;
- ✅ DNS: записи A для `@` и `www` указывают на хостинг 37.140.192.224;
- ✅ SSL-сертификат Let's Encrypt выпущен.

Осталось шесть шагов.

---

## Шаг 1. Включить https и прибраться

1. ISPmanager → **Сайты** → дважды щёлкнуть **zachanku.ru**.
2. Проверить, что в поле SSL-сертификата выбран сертификат типа **Let's Encrypt**.
3. Включить **«Перенаправлять HTTP-запросы в HTTPS»** → **Сохранить**.
4. **Менеджер файлов** → `www/zachanku.ru` → удалить `test.txt` и всё, что панель положила туда сама (например `index.html` с заглушкой).
   Папка должна остаться пустой.
5. **SSL-сертификаты** → старые самоподписанные `zachanku.ru` и `zachanku.ru_le1`, если они остались и не используются,
   можно удалить. Не обязательно.

Проверка: https://zachanku.ru открывается с замком в адресной строке (страница пока пустая или с ошибкой 403 — это нормально).

## Шаг 2. Telegram-канал

1. В Telegram: **Новый канал** → название «бег#заЧанку» → тип **Публичный** → ссылка `zachanku`.
2. Если имя `zachanku` занято и вы взяли другое, запомните его: на шаге 4 его нужно будет вписать в `config.json`.
3. Аватарка канала: файл `logo-wordmark-dark.png` или `favicon.svg` из комплекта.

## Шаг 3. Данные для FTP

В личном кабинете REG.RU: **Хостинг → ваш тариф → «Доступы»** (или письмо «Хостинг подключён»). Выпишите:

| Что | Где взять | Пример |
|---|---|---|
| FTP-сервер | «Доступы» → FTP | адрес сервера или IP `37.140.192.224` |
| Логин | «Доступы» → FTP | `u3663650` (этот логин виден в менеджере файлов) |
| Пароль | «Доступы» → FTP | пароль от FTP / хостинга |
| Папка сайта | уже известна | `www/zachanku.ru/` |

Если пароль FTP неизвестен, его можно сменить в том же разделе «Доступы».

## Шаг 4. GitHub

1. Зарегистрироваться на **github.com** (если аккаунта нет).
2. Справа вверху **+ → New repository** → имя `zachanku` → **Public** → **Create repository**.
   Публичный — потому что так автосборка бесплатна без ограничений. Паролей в файлах нет, они хранятся отдельно.
3. На странице репозитория ссылка **«uploading an existing file»** → перетащить в окно **всё содержимое** распакованной папки
   `zachanku` (не саму папку, а то, что внутри) → внизу **Commit changes**.
4. Проверить, что загрузилась скрытая папка `.github`. Если её нет в списке файлов:
   **Add file → Create new file** → в поле имени написать `.github/workflows/site.yml` →
   вставить содержимое файла `site.yml` из архива → **Commit changes**.
5. Если имя канала не `zachanku`: открыть `config.json` → карандаш → поменять `"telegram_channel"` → **Commit changes**.

## Шаг 5. Пароли для выкладки (Secrets)

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Создать четыре секрета по одному:

| Name | Secret |
|---|---|
| `FTP_SERVER` | FTP-сервер из шага 3 |
| `FTP_USERNAME` | `u3663650` |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_DIR` | `www/zachanku.ru/` |

## Шаг 6. Первый запуск

1. Вкладка **Actions**. Если GitHub спросит — нажать **«I understand my workflows, go ahead and enable them»**.
2. Слева **site** → справа **Run workflow** → **Run workflow**.
3. Через 1–2 минуты появится зелёная галочка. Открыть **https://zachanku.ru** — сайт на месте.

**Если красный крестик** — нажать на запуск и посмотреть, какой шаг упал:
- «Выложить на REG.RU по FTP», ошибка соединения или TLS → в файле `.github/workflows/site.yml` поменять
  `protocol: ftps` на `protocol: ftp` (карандаш → Commit) — запуск повторится сам.
- «Выложить на REG.RU по FTP», ошибка логина → проверить секреты `FTP_USERNAME` и `FTP_PASSWORD`.
- Любая другая ошибка → скриншот мне.

## После запуска

**Поиск (через 1–2 дня после запуска):**
1. **Яндекс.Вебмастер** → добавить `https://zachanku.ru` → способ подтверждения **мета-тег** → скопировать код из `content="…"`.
2. На GitHub: `config.json` → карандаш → вставить код в `"yandex": ""` → Commit. Через пару минут сайт пересоберётся →
   в Вебмастере нажать **«Проверить»**.
3. В Вебмастере: **Индексирование → Файлы Sitemap** → `https://zachanku.ru/sitemap.xml`;
   **Представление в поиске → Региональность** → Мытищи.
4. **Google Search Console** → то же самое, код в `"google": ""`, затем добавить sitemap.

**Как жить дальше:**
- **Анонс или отмена:** пост в канале с `#анонс` или `#отмена` → через 30 минут он на сайте.
- **Новая статья:** GitHub → `content/posts` → **Add file → Create new file** → формат в README → Commit. Или пришлите текст мне.
- **Новый трек на 10 км:** пришлите GPX в чат — перерисую схему и пришлю обновлённые файлы.

**Запасной ручной способ** (если FTP с GitHub не заработает): я собираю сайт и присылаю архив `dist`,
вы загружаете его в ISPmanager → Менеджер файлов → `www/zachanku.ru` → **Загрузить** → затем **Архив → Распаковать**.
Анонсы из Telegram в этом варианте сами обновляться не будут.
