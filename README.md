# бег#заЧанку

Сайт вечерней пробежки по четвергам: главная с маршрутом, блог, автоматический анонс из Telegram.
Сайт статический: обычные HTML-файлы, без базы данных, cookies и счётчиков.

## Что где лежит

| Путь | Что это |
|---|---|
| `config.json` | Домен, название, канал Telegram, точка сбора, коды Яндекса и Google |
| `DEPLOY-REGRU.md` | Как опубликовать сайт на REG.RU |
| `content/posts/*.md` | Статьи блога, одна статья — один файл |
| `data/announce.json` | Последний анонс из канала (обновляется сам) |
| `static/` | Стили, скрипт, шрифты, иконка, трек GPX |
| `scripts/fetch_announce.py` | Забирает анонс из канала |
| `build.py` | Собирает сайт в папку `dist/` |
| `.github/workflows/site.yml` | Автосборка и выкладка на REG.RU по FTP |

## Запуск

Пошаговая инструкция для REG.RU — в файле **DEPLOY-REGRU.md**: домен, хостинг, SSL, FTP, GitHub, первый запуск.

## Анонс из Telegram

Публикуйте в канале пост с меткой:

- `#анонс` — текст появится на главной под таймером: «Анонс из канала»;
- `#отмена` — таймер сменится на «в этот четверг не бежим», текст поста покажется красной плашкой.

Сайт проверяет канал каждые 30 минут. Анонс показывается, только если он опубликован не раньше
чем за 6 дней до ближайшего четверга, так что старые анонсы исчезают сами.
Сами метки #анонс и #отмена в текст на сайте не попадают.

> GitHub отключает расписание в репозиториях, где 60 дней не было изменений.
> Новая статья раз в пару месяцев решает вопрос; можно и просто нажать *Run workflow*.

## Как добавить статью

Создайте файл `content/posts/ГГГГ-ММ-ДД-адрес-статьи.md`:

```
---
title: Заголовок статьи
slug: adres-stati
date: 2026-10-05
description: Одно-два предложения для поиска и превью в Telegram.
tags: снаряжение, зима
draft: false
---

Текст статьи в Markdown. ## Подзаголовок, **жирный**, списки через «- ».
```

- `draft: true` — черновик: на сайт не попадает. Посмотреть его можно командой `python build.py --drafts`.
- Блоки `<div class="todo">…</div>` в черновике — места, где нужны ваши детали. Перед публикацией их надо убрать.
- Дисклеймер «не рекомендация» добавляется в каждую статью автоматически, в начале и в конце.

## Поиск: Яндекс и Google

Сайт уже готов к индексации: у каждой страницы свои заголовок и описание, есть `sitemap.xml`, `robots.txt`,
RSS-лента `feed.xml`, картинка-превью `og.png`, разметка schema.org (Event для пробежки, BlogPosting для статей).

После запуска:

1. **Яндекс.Вебмастер** (webmaster.yandex.ru): добавьте сайт, выберите подтверждение мета-тегом,
   скопируйте код из `content="…"` в `config.json` → `verification.yandex`, сохраните — сайт пересоберётся.
   Затем: *Индексирование → Файлы Sitemap* → `https://zachanku.ru/sitemap.xml`;
   *Представление в поиске → Региональность* → Мытищи.
2. **Google Search Console** (search.google.com/search-console): то же самое, код в `verification.google`,
   затем добавьте sitemap.
3. Проверьте разметку: validator.schema.org и webmaster.yandex.ru/tools/microtest.

Счётчики (Яндекс.Метрика, Google Analytics) не нужны: статистика запросов есть в самих Вебмастере и Search Console.
Если всё же поставите счётчик, понадобятся политика обработки персональных данных, согласие посетителя
и уведомление Роскомнадзора (152-ФЗ).

## Локальная проверка

```
pip install -r requirements.txt
python build.py --drafts
python -m http.server -d dist 8000   # и откройте http://localhost:8000
```

Шрифты Tektur, Golos Text и JetBrains Mono распространяются по лицензии SIL Open Font License и хранятся на сайте,
поэтому браузер посетителя не обращается к Google Fonts.
