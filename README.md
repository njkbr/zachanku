# бег#заЧанку

Сайт zachanku.ru — пробежка по четвергам в Мытищинском лесопарке. Канал: t.me/zachanku.

Сайт статический, без базы данных и счётчиков. Собирается и выкладывается сам через GitHub Actions: при каждом изменении в репозитории и каждые 30 минут.

## Файлы

- `config.json` — название, канал, точка сбора, время.
- `content/posts/` — статьи блога, один файл на статью.
- `static/` — стили, скрипты, шрифты, трек маршрута.
- `build.py` — сборка сайта.
- `scripts/` — анонс и погода для сайта, публикация статей в канал.
- `hosting/zachanku-pull.sh` — скрипт на хостинге, который забирает готовый сайт из ветки `site`.

## Анонсы

Пост в канале с `#анонс` показывается на главной, с `#отмена` — отменяет ближайший четверг. Учитывается последний пост с меткой, не раньше чем за 6 дней до четверга.

## Статьи

Новый файл в `content/posts/` с шапкой:

```
---
title: Заголовок
slug: adres-stati
date: 2026-10-05
description: Короткое описание.
tags: тег, тег
draft: false
---
```

С `draft: true` статья на сайт не попадает. После публикации бот сам выкладывает её в канал.

## Доступы

Хостинг и домен — REG.RU. GitHub собирает сайт и кладёт его в ветку `site`, хостинг каждые 5 минут забирает её сам: Планировщик CRON в ISPmanager запускает `/zachanku-pull.sh`. Журнал обновлений — `/zachanku-pull.log` на хостинге (скрипт пишет его сам). Тот же скрипт раз в 15 минут запускает сборку на GitHub, потому что запуски по расписанию GitHub часто опаздывают; для этого на хостинге лежит токен `/.zachanku-dispatch-token` (GitHub, право Actions: Read and write, продлевать раз в год). Токен бота хранится в Settings → Secrets репозитория.

Если в репозитории 60 дней не было изменений, GitHub отключает автосборку по расписанию. Включить снова: Actions → site → Run workflow.
